# DevBoard

DevBoard is a polished developer productivity dashboard built for the Hack the Web open-source contribution event. It gives contributors a clean workspace for tracking tasks, monitoring progress, and engaging with project work.

## Overview

- Modern dashboard for issue-based contributions
- Responsive task tracking with filtering and search
- Theme switcher and dashboard overview cards
- Static frontend built with HTML, CSS, and vanilla JavaScript

## Features

- Navigation and summary cards
- Add, complete, and delete tasks
- Task priority levels: Low, Medium, High
- Search and filter controls
- Loading state and notification feedback
- Dark/light theme toggle
- Activity log panel
- Browser-local theme preference and task-state handling

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)

## Local Development

1. Clone the repository.
2. Open `index.html` directly in your browser, or run a lightweight static file server such as VS Code Live Server.
3. Confirm the dashboard loads correctly and the interactions behave as expected.
